# Laboratory Assignment - Task 14: Parcels

This repository contains solutions for the Modern Programming Languages laboratory assignment completed by Murad Shahveranli.

## Differences Between Imperative and Functional Solutions
In the imperative solution (Task 1), explicit `for` loops and `if/elif` conditions are used to process data step-by-step and modify variables directly. In contrast, the functional solution (Task 2) avoids loops entirely by utilizing pure functions along with built-in higher-order functions like `filter()`, `map()`, and `reduce()`. This makes the code more declarative, focusing on what operations to perform rather than how to execute them procedurally.
